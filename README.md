# Md Ahsanul Haque: Academic Website

Personal academic website of Md Ahsanul Haque.
Live site: <https://mahsanul.github.io>

The site is built with [Jekyll](https://jekyllrb.com) and hosted on GitHub Pages.
It is designed to stay useful during and after the Ph.D.

## How to edit the website

**Read [WEBSITE_GUIDE.md](WEBSITE_GUIDE.md).** It explains, step by step, how to update
the bio, news, publications, CV, teaching, projects, talks, notes, colors, and more.

Most content is in the `_data/` folder. To update the website, edit a file there on GitHub,
commit the change to the `main` branch, and wait 1 to 3 minutes.

## Quick map

| Folder or file | Content |
|---|---|
| `_data/` | Your information: profile, news, publications, CV items |
| `_pages/`, `index.html` | The pages |
| `files/` | PDF files (CV, slides, posters) |
| `images/` | Photos and icons |
| `assets/css/site.css` | Colors and fonts (see the top of the file) |
| `_layouts/`, `_includes/`, `assets/js/` | Page design and scripts (rarely edited) |
