Put your downloadable files in this folder: your CV (PDF), slides, posters, and papers.

IMPORTANT: Everything in this folder is public on the internet.
Do not upload private documents.

Your CV file must be named  Ahsanul_Haque_CV.pdf
(or you must change "cv_file" in _data/profile.yml to the new name).
When the file exists, the "Download CV" buttons appear on the website automatically.

You can link to any file in this folder from the website, for example:  /files/my-slides.pdf
See WEBSITE_GUIDE.md for more help.
